# 03 数据分析与可视化

**目标：**掌握统计指标、plots 与批量实验。  

## 理论讲解
- 统计指标必须对应科学问题与假设。  
- plots 用于观察趋势、稳态与振荡。  
- 随机性要求多次运行与参数对比。  

## 关键语法与概念
- **统计汇总**：`count`、`sum`、`mean`、`max`、`min`。  
- **报表过程**：`to-report` 用于封装统计指标。  
- **绘图**：`set-current-plot`、`set-current-plot-pen`、`plot`。  

## 实践任务（建议 4 课时）
1. **指标定义**：实现 `count` / `mean` 等指标。  
2. **可视化**：绘制狼羊数量与平均能量曲线。  
3. **批量实验**：用 BehaviorSpace 比较不同参数组合。  
4. **结果解读**：总结稳定区间与崩溃阈值。  

## 代码 Demo
- 见 `demos/03-plotting-stats.nls`（统计与绘图）。  

## 理论要点速记
- `to-report` 用于封装可复用统计指标。  
- 通过多次运行获取平均结果，提高结论可靠性。
