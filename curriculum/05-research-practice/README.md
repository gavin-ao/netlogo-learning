# 05 科研实践与可复现性

**目标：**掌握模型验证、校准与研究报告规范。  

## 理论讲解
- 可复现性：固定随机种子、记录参数与运行次数。  
- 校准与验证：用真实数据对照模型输出。  
- 结果报告：用图表与统计指标呈现结论。  

## 关键语法与概念
- **随机种子**：`random-seed` 固定随机序列，保证可复现。  
- **数据导出**：`export-world`、`export-plot`、`file-open`/`file-write`。  
- **实验记录**：用 `globals` 保存运行编号与参数组合。  

## 实践任务（建议 3 课时）
1. **可复现运行**：固定随机种子并记录实验日志。  
2. **模型校准**：对照真实数据调整关键参数。  
3. **报告输出**：生成 plots 与统计表格并撰写总结。
