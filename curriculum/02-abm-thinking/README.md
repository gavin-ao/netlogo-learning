# 02 建模思维（ABM 基础）

**目标：**掌握 Agent-Based Modeling 的建模流程与规则设计。  

## 理论讲解
- 建模五步法：问题 → 假设 → Agent/环境 → 规则 → 验证。  
- 局部规则与涌现：简单规则可产生复杂群体行为。  
- 解释性：规则需要与现实假设可对应。  

## 关键语法与概念
- **breed**：用 `breed [ wolves wolf ]` 定义新 agent 类型与单数名称。  
- **邻域与感知**：`neighbors`、`in-radius`、`turtles-here` 用于局部交互。  
- **随机性**：`random`、`random-float`、`one-of` 帮助构建随机行为。  

## 实践任务（建议 4 课时）
1. **假设清单**：列出“狼羊模型”的假设并映射到规则。  
2. **规则对比**：比较随机移动与群聚规则的空间差异。  
3. **实验设计**：固定羊数量，改变狼数量，观察稳态与崩溃。  
4. **可解释性**：为每条规则写一句“现实含义”。

- 捕食是局部互动规则，群体数量变化是涌现现象。  
- 调整初始数量与能量消耗可快速探索系统稳定性。
