# 04 高级建模与扩展

**目标：**构建更复杂的空间、网络与自适应模型。  

## 理论讲解
- 空间异质性会改变局部互动结构。  
- 网络拓扑影响扩散效率与协作关系。  
- 规则可以进化或自适应。  

## 实践任务（建议 4 课时）
1. **空间异质性**：随机初始化 patch 资源并观察聚集。  
2. **网络拓扑**：对比随机网络与小世界网络的扩散速度。  
3. **规则学习**：根据成功率调整行为概率。  
4. **扩展插件**：使用 GIS 扩展加载真实地图。  

## 代码 Demo
- 见 `demos/04-network-diffusion.nls`（网络扩散）。  

## 理论要点速记
- links 可替代空间邻近关系，强调社会连接。  
- 拓扑结构差异是扩散速度差异的核心来源。
